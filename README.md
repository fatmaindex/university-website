# 🎓 University Website (EduFord)

A professional, multi-page educational website built with **HTML5**, **CSS3**, and **JavaScript**. This project features a complete user interface for a university, including course listings, campus details, and a functional contact system.

---

## 🛠 Key Technical Implementation

* **Responsive Navigation:** A sticky navigation bar that stays fixed at the top during scrolling, with a custom JavaScript toggle menu for mobile devices.
* **Modern CSS Layouts:** Used **Flexbox** for the grid systems in sections like "Courses", "Campus", and "Facilities".
* **Interactive UI Elements:** * Hover effects on campus images with sliding text layers.
    * Integrated **Google Maps** iframe in the contact section.
    * Custom-styled testimonials with FontAwesome star ratings.
* **Multi-Page Structure:** Separate, linked HTML files for `Home`, `About`, `Courses`, `Blog`, and `Contact` pages.
* **Typography & Icons:** Integrated **Google Fonts** (Poppins, Cairo, Work Sans) and **FontAwesome 6.2.0** for a high-quality visual experience.

## 📂 Project Architecture

```text
├── css/             # Stylesheets (all.min.css)

├── index.html       # Landing Page
├── about.html       # About the university
├── courses.html     # Academic programs
├── blog.html        # News and updates
└── contact.html     # Contact form and location

🚀 Responsive Design
The project is fully responsive across different screen sizes:

Desktop: Multi-column layouts using flex-basis.

Mobile (under 700px): Transitions to a single-column layout with a side-drawer navigation menu.
